# ИТМО Синтез речи

### Общее
**Авторы:** Рыбин С. В., Чирковский А. Д, Claude Opus 5

**Описание:** Проект содержит набор лабораторных работ, посвященный синтезу речи на русском языке

**Ключевые слова:** speech synthesis, machine learning, deep neural network.

**Наборы данных:** Основной набор данных в данном курсе это [Ruslan](https://ruslan-corpus.github.io/).

**Содержимое:** Курс состоит из пяти лабораторных работ, посвященных процессу создания полноценного тракта синтеза речи на русском языке. Каждая лабораторная работа, кроме последней, включает этап обработки исходного набора данных и создание компонента тракта синтеза речи. Последняя лабораторная работа посвящена объединению разработанных компонентов в полноценный тракт синтеза: из текста в речь.

```
текст ─▶ 1. нормализация ─▶ 2. паузы ─▶ 3. транскрипция ─▶ 4. акустическая модель ─▶ 5. сервис ─▶ аудио
```

- **Лабораторная работа 1.** [Нормализация текста](labs/lab1_text/): Фильтрация исходных текстовых данных и обучение текстового нормализатора
- **Лабораторная работа 2.** [Просодика](labs/lab2_pauses/): Предсказание мест пауз в речи и их длительности по тексту; Разметка корпуса по словам
- **Лабораторная работа 3.** [Транскрипция (G2P)](labs/lab3_g2p/): Преобразование из графем в фонемы по тексту; Разметка корпуса по фонемам
- **Лабораторная работа 4.** [Акустическая модель](labs/lab4_acoustic/) : Обучение модели синтеза речи на фонемах FastSpeech-2
- **Лабораторная работа 5.** [Сервис синтеза](labs/lab5_service/): Разработка сервиса синтеза речи, подключение вокодера


**Работы идут последовательно.** Лабораторная работа N в качестве входа требует то, что было получено на этапе N-1. 

**Почему FastSpeech-2?** Эта модель является одной из последних моделей, в которой все этапы традиционного тракта синтеза речи отделены друг от друга. Более современные агрегируют несколько этапов в один и делают их менее наглядными для изучения, и при этом зачастую более требовательны в ресурсах для обучения.


## Настройка среды

Для лабораторных работ 1-3 необходимо достаточно лаконичное окружение и даже не требуется GPU, однако для работ 4-5 GPU крайне рекомендуется к использованию.

Работа репозитория проверялась на следующем окружении, с видеокартой GeForce 1080Ti:
```
python == 3.11
ubuntu == 22.04
cuda == 12.1
pytorch == 2.5.1
```
Использование более свежего или более старого окружения может привести к неожиданным проблемам.

Выполнять задания желательно внутри виртуальной среды:

**Создание виртуальной среды**
```bash
python3.11 -m venv .venv
. .venv/bin/activate
python -m pip install --upgrade pip
```

### Базовая настройка окружения 
Достаточна для выполнения работ 1-3
```bash
pip install -r requirements.txt
```
### Расширенная настройка окружения 
Необходима для выполнения работ 4-5

**Установка PyTorch -- с соответствующей вашему окружению версией cuda**

```bash
pip install torch==2.5.1 torchaudio==2.5.1 --index-url https://download.pytorch.org/whl/cu121
```

**Валидация корректности установки PyTorch**

```bash
python -c "import torch; print(torch.__version__, torch.cuda.is_available(), torch.cuda.get_device_capability(0))"
```

Ожидается `2.5.1+cu121 True (6, 1)`.

**Установка репозитория coqui-TTS**
Необходимо установить не основной репозиторий, а данный форк, который содержит необходимые модификации для работы с моделями синтеза речи в рамках курса. Либо можно их имплементировать самостоятельно!
```bash
pip install "git+https://github.com/Arbaletos/coqui-ai-TTS.git@tts-course-itmo-2026-m1"
```

**Дополнительные зависимости**

```bash
pip install -r requirements.txt
```

## Данные

Корпус [RUSLAN](https://ruslan-corpus.github.io/) — речевые данные, записанные одним мужским диктором 22 200 фраз, около 31 часа, 44100 Гц. 

Статья с описанием корпуса: [ARXIV](https://arxiv.org/abs/1906.11645)

В рамках практикума требуется работать с частотой дискретизации 22050 Гц. Данные в частоте дискретизации 22050 можно получить [здесь](https://www.kaggle.com/datasets/freezerainml/ruslan) или сделать редискретизацию самостоятельно.

Скачивается и распаковывается на первой лабораторной.
