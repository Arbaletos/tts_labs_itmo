**4.Общая концепция и характеристики фильтра и нормализатора**
**TextFilter** — это бинарный классификатор, который решает: можно ли использовать предложение для обучения TTS-модели. Random Forest предсказывает по 17 признакам: 1) количество аббревиатур, 2) количество акронимов, 3) количество технических символов, 4) количество цифр, 5) количество латинских букв, 6) количество множественных знаков препинания, 7) количество кавычек, 8) количество тире, 9) количество скобок, 10) доля плохих символов, 11) отношение пунктуации к словам, 12) средняя длина слова, 13) количество слов, 14) количество предложений, 15) нормализованная длина текста, 16) доля заглавных букв, 17) лексическое разнообразие

**TextNormalizer** — препроцессор, который приводит текст к стандартному виду, не меняя слова. Работает только со знаками препинания и Unicode-символами.
Производит действия: NFC-нормализация Unicode, замена разных варианто тире на единый знак, замена разных кавычек на единые "ёлочки", удаление технических символов, замена многоточий на единый знак Unicode, схлопывание множественных знаков, удалениие лишних пробелов.
